# Struktogramme (Nassi-Shneiderman-Diagramme)

Struktogramme und Programmablaufpläne zu einfachen Programmen, erstellt mit Structorizer. Entstanden in der Umschulung zur Fachinformatikerin für Systemintegration (GFN).

## Inhalt

| Datei | Thema |
|---|---|
| `hundealter.nsd` | Hundealter in Menschenjahren berechnen |
| `begruessung.nsd` | Einfaches Begrüßungsprogramm |
| `portokosten.nsd` | Portokosten berechnen |
| `urlaubsanspruch.nsd` | Urlaubsanspruch berechnen |
| `programmablaufplaene_1-10.pap` | Programmablaufpläne 1–10 |
| `zahlen_vergleichen.pap` | Programmablaufplan: Zahlenvergleich |
| `zahlenreihe_ohne_7.pap` | Programmablaufplan: Zahlenreihe ohne 7 |
