# Struktogramme (Nassi-Shneiderman-Diagramme)

Struktogramme und Programmablaufpläne zu einfachen Programmen, erstellt mit Structorizer. Entstanden in der Umschulung zur Fachinformatikerin für Systemintegration (GFN).

## Inhalt

| Datei | Thema |
|---|---|
| `StructorizerNSD 1-10 Hundealter.nsd` | Hundealter in Menschenjahren berechnen |
| `StructorizerNSD 2-10 Begrüßung.nsd` | Einfaches Begrüßungsprogramm |
| `StructorizerNSD 3-10 Portokosten.nsd` | Portokosten berechnen |
| `StructorizerNSD 4-10 Urlaubsanspruch.nsd` | Urlaubsanspruch berechnen |
| `PAP 1_10 ÜBUNGEN.pap` | Programmablaufpläne 1–10 |
| `Zwei Zahlen genau vergleichen.pap` | Programmablaufplan: Zahlenvergleich |
| `Zahlenreiche ohne 7.pap` | Programmablaufplan: Zahlenreihe ohne 7 |

## Werkzeug

Structorizer (kostenlos, https://structorizer.fisch.lu)
